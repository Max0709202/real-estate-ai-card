# 体験版（デモ）名刺で物件提案・担当チャットを見せる

対象: `https://www.ai-fcard.com/card.php?slug=demo`（`business_cards.is_demo = 1` の名刺）

## 背景

体験版名刺はSMS認証を行わず、**開いた方ごとに使い捨てのチャットセッション**を発行する
（`backend/api/chat/session/start.php`）。そのため担当が提案した物件も担当連絡のやり取りも
「その体験者のセッション」にしか残らず、次にデモを開いた方の画面は空のままだった。

商談で「実際に近い環境」をお見せできるよう、**あらかじめ用意した見本を新しい体験セッションへ
自動で複製する**ようにした。

## 見本（サンプル）の作り方

1. 体験版名刺のアカウントでログインする。
2. 「顧客管理」→ 顧客ページの事前作成で、**姓に「見本」**と入力して作成する
   （メールアドレスは社内のもので可。環境変数 `DEMO_SAMPLE_CUSTOMER_LAST_NAME` で姓は変更可）。
3. 作成された「見本」のお客様を開き、
   - **物件選定** … お見せしたい物件を登録する（販売図面の取り込み／URL／手入力）。
     顧客側に見せる販売図面は、マスク編集を確定して公開状態にしておく。
   - **担当連絡** … 担当からのメッセージを数件送っておく。
4. これで完了。以後、体験版名刺を開いた方全員の画面に同じ内容が複製される。

見本をやめたいときは、その「見本」顧客ページを削除（またはゴミ箱へ移動）する。

## 複製されるもの・されないもの

| 対象 | 複製 |
| --- | --- |
| 物件（`properties`）／画像・販売図面・資料の行／フォルダー | する（上限20件・`DEMO_SAMPLE_MAX_PROPERTIES`） |
| 担当連絡のメッセージ（`chat_messages.channel = 'contact'`） | する（上限100件。担当の発言は未読＝新着バッジが出る） |
| AIチャットの履歴 | しない（体験者ごとに最初のご挨拶から始める） |

画像の**実ファイルは複製せず、見本と同じファイルを参照する**（体験用の読み取り前提）。
そのため次の2点で実ファイルを保護している。

- 複製行の `expires_at` は `NULL`。保存期限の掃除（`cron/cleanup-expired-properties.php`）が
  見本と共用のファイルを消さない。
- 物件削除（`backend/api/property/delete.php`）と体験セッションの掃除
  （`cron/cleanup-demo-sessions.php`）は、**他の物件行から参照されていないファイルだけ**削除する。

## その他の挙動

- 体験セッションの有効期限（既定24時間・`CHAT_DEMO_SESSION_TTL`）は、名刺を開くたびに延長される。
  商談の途中で履歴と提案物件が消えない。
- 体験セッションにはダミーのメールアドレス（`demo@example.com`）が入っているため、
  物件提案・担当連絡のお知らせメールは送信しない（`customerNotifyIsDemoSession()`）。
- 期限切れの体験セッションは `cron/cleanup-demo-sessions.php` が削除する。
  複製された物件行・フォルダーも併せて削除される。

## その場で個別に提案したい場合

体験版名刺のアカウントでログインし、「顧客管理」で該当の体験セッション
（お名前は「体験 ユーザー」・最新のアクセス順で上位）を開けば、通常の顧客と同じように
物件選定・担当連絡が使える。お客様の画面にはそのまま反映される。
