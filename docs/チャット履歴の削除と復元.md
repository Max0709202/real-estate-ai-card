# チャット履歴の削除と復元（ゴミ箱方式）

- 版: v1.0（2026-08-13）
- 対象: マイページ（edit.php）「チャット履歴・顧客一覧」の履歴削除

## 1. 背景

従来、マイページの「削除」はセッションと関連データ（メッセージ・ヒアリング内容・
連絡先・ローン入力・AI記憶）を即座に実体削除していたため、**誤って削除すると復元できなかった**。
また、実体削除ではお客様側のセッションごと消えるため、**お客様のチャット画面からも
過去のやり取りが消え、専用ページが開けなくなる**状態になっていた。

## 2. 変更後の挙動

### 担当者（マイページ）

| 操作 | 挙動 |
|---|---|
| 履歴の「削除」／「選択した履歴を削除」／詳細の「この履歴をゴミ箱へ」 | ゴミ箱へ移動（ソフト削除）。一覧と未読バッジから外れるだけで、実体は残る |
| 「ゴミ箱（削除した履歴）」→「復元する」 | 一覧に戻す。メッセージ・ヒアリング内容・添付もそのまま戻る |
| 「ゴミ箱」→「完全に削除」 | 実体ごと削除（復元不可）。ゴミ箱に入っている履歴だけが対象 |

保持期間は既定 **30日**。環境変数 `CHAT_SESSION_TRASH_RETENTION_DAYS`（1〜365）で変更できる。
期限を過ぎた履歴は cron が完全に削除する。

### お客様側

- **影響しない。** セッション行もメッセージ行も残るため、お客様の専用ページは今までどおり開け、
  過去のやり取りも消えない。SMS認証済みの端末からの復帰も従来どおり。
- 削除中のセッションにお客様から新しいメッセージが届いた場合、そのセッションは
  **自動的にゴミ箱から一覧へ戻る**（担当者が新着を見落とさないようにするため）。
- 「完全に削除」または保持期限切れの削除を行った場合に限り、お客様側からも履歴が消える。

## 3. 実装

| 種別 | パス | 役割 |
|---|---|---|
| 列 | `chat_sessions.deleted_at` / `deleted_by_user_id` | ソフト削除の状態。移行は `backend/database/migrations/20260813_add_chat_session_soft_delete.sql`（未適用でも実行時に自動補完） |
| ヘルパー | `backend/includes/chat-session-trash-helper.php` | 列の補完・保持期間・復元期限の算出・自動復帰・実体削除 |
| API | `backend/api/chat/session-delete.php` | ゴミ箱へ移動（ソフト削除） |
| API | `backend/api/chat/session-restore.php` | ゴミ箱から復元 |
| API | `backend/api/chat/session-purge.php` | ゴミ箱の履歴を完全に削除 |
| API | `backend/api/chat/sessions.php` | `?deleted=1` でゴミ箱一覧（`deleted_at` / `purge_at` / `days_left` を返す） |
| API | `backend/api/chat/agent/poll.php` | 未読バッジの集計からゴミ箱の履歴を除外 |
| API | `backend/api/chat/send.php` | お客様の新着でゴミ箱から自動復帰 |
| UI | `edit.php` / `assets/css/edit.css` | ゴミ箱の一覧・復元・完全削除 |
| cron | `backend/cron/cleanup-deleted-chat-sessions.php` | 保持期限を過ぎた履歴の完全削除 |

## 4. 運用（cron 登録）

```
10 4 * * * /usr/bin/php /home/xs013436/ai-fcard.com/public_html/backend/cron/cleanup-deleted-chat-sessions.php
```

対象件数の確認のみ（削除しない）:

```
/usr/bin/php /home/xs013436/ai-fcard.com/public_html/backend/cron/cleanup-deleted-chat-sessions.php --dry-run
```

cron を登録しない場合、ゴミ箱の履歴は自動削除されず残り続ける（復元は引き続き可能）。
